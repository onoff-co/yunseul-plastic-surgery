# Implementation Plan: 윤슬성형외과 프리미엄 사이트 확장

## Overview

윤슬성형외과의 콘텐츠와 라우팅을 유지하면서, 시술 정보 탐색·신뢰 형성·상담 준비 흐름을 확장한다. YSPS 로고와 옵시디언 블랙·웜 아이보리·샴페인 골드 팔레트를 공통 디자인 토큰으로 사용한다.

## Architecture Decisions

- 현재 프로젝트의 React + Vite + JSX 구조를 유지하고, 전체 TypeScript 마이그레이션은 이번 범위에서 하지 않는다.
- 신규 정보 페이지는 기존 `PageLayout`과 공통 콘텐츠 패턴을 재사용한다.
- 확인되지 않은 예약·후기·가격·의료진·연락처 정보는 게시하지 않는다. 상담 양식이 정보를 전송하지 않는다는 점을 명확히 알린다.
- 모바일 상담 전환은 하단 고정 바와 기존 상담 폼을 연결하되, 콘텐츠를 가리지 않도록 안전 영역을 확보한다.
- 의료 정보에는 개인차를 안내하고, AI 생성 이미지는 실제 환자·시술 결과와 구분한다.

## Task List

### Phase 1: 구조와 공통 전환 요소

- [ ] 신규 라우트와 페이지 제목 추가: 전후 사례, 후기, 비용, 공지, FAQ, 개인정보, 이용약관
- [ ] 헤더 메뉴를 요구된 핵심 메뉴로 정리
- [ ] 푸터에 사업자·정책·의료광고 안내 링크 추가
- [ ] 모바일 하단 상담·전화·예약 액션 바 추가

### Phase 2: 핵심 정보 페이지

- [ ] 전후 사례 갤러리와 부위 필터
- [ ] 후기 목록과 시술 유형 필터
- [ ] 비용 안내와 이벤트 조건
- [ ] 공지사항·이벤트·FAQ 페이지

### Checkpoint: Core Pages

- [ ] 라우트 테스트 통과
- [ ] 모든 신규 페이지 직접 접근 가능
- [ ] 모바일에서 가로 스크롤 없음
- [ ] 홈에서 상담 전환 경로가 보임

### Phase 3: 신뢰 요소와 마감

- [ ] 병원 소개에 안전 관리·진료 프로세스 보강
- [ ] 의료진 페이지에 학술·자격 정보와 상담 연결 보강
- [ ] 시술 상세에 마취·회복·주의사항·부작용·사후관리 섹션 보강
- [ ] 브라우저 화면·접근성·폼 상태 검증

### Checkpoint: Complete

- [ ] 테스트와 빌드 성공
- [ ] 데스크톱·모바일 주요 페이지 확인
- [ ] 기존 경로와 상담 폼 동작 회귀 없음

## Risks and Mitigations

| Risk | Impact | Mitigation |
| --- | --- | --- |
| 기존 작업 변경사항과 신규 수정 충돌 | High | 현재 dirty worktree를 보존하고 필요한 파일만 수정 |
| 확인되지 않은 의료 정보가 실제 사실로 오인될 가능성 | High | 미확인 정보는 게시하지 않고 AI 생성 이미지와 실제 결과를 명확히 구분 |
| 페이지 확장으로 모바일 길이와 CTA가 과해짐 | Medium | 하단 고정 액션은 모바일 전용으로 제한하고 섹션 간 우선순위 유지 |
| 신규 라우트 누락 | Medium | 라우트 단위 테스트를 추가하고 직접 URL 접근을 확인 |
