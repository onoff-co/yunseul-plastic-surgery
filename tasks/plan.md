# Implementation Plan: 윤슬성형외과 디자인 고도화

2026-10-27. 이전 확장 작업 기록은 `plan-2026-10-site-expansion.md`에 보관했다.

## Overview

기능·콘텐츠·URL은 유지하고, 겹겹이 덮어쓴 스타일 구조를 하나의 디자인 시스템으로 정리한 뒤 홈·상세·모바일 화면을 개선한다. 블랙·웜 아이보리·샴페인 골드 팔레트와 YSPS 로고를 유지한다.

## 현재 진단

- CSS 19개 파일이 `main.jsx`에서 순서대로 덮어쓴다. `yunseul-redesign.css`만 2,003줄.
- `:root`가 9개 파일에서 12번 선언되고 `--ink`·`--paper`·`--accent`가 각 3회 다른 값으로 재정의된다. `tokens.css`는 네이비·테라코타지만 실제 화면은 블랙·골드.
- 폰트 변수 3벌(`--display`, `--nana-serif`, `--studio-serif`), font-size 값 171종, `!important` 26개.
- 홈: 첫 화면 행동 버튼 두 그룹 중복, 하단 진료 바의 골드 칸이 오른쪽 끝까지 닿지 않음.
- 모바일 홈: 메인 사진이 박스처럼 보임, 진료 바가 이름만 빽빽함.
- 상세: 모든 섹션이 "제목 + 구분선 + 2열 텍스트" 한 가지 패턴, 본문이 작고 연함, 상단 사진이 작음.
- 같은 인물 이미지가 여러 페이지에서 반복.

## Architecture Decisions

- React 19 + Vite + Vanilla CSS 유지. UI 라이브러리·CSS 프레임워크를 추가하지 않는다.
- 토큰은 `tokens.css` 한 곳에서만 정의한다. 역할 이름(`--color-ink`, `--color-surface`, `--color-accent`, `--color-line` 등), 타입 스케일(`--fs-*`), 간격(`--space-*`).
- 스타일 파일은 `tokens / base / layout / components/* / pages/*` 구조. 덮어쓰기 전용 파일을 만들지 않는다.
- 미확인 의료 정보·주소·가격·후기는 게시하지 않는다. AI 생성 이미지 고지를 유지한다.
