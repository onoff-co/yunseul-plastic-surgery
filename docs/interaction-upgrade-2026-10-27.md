# 메뉴·상세페이지·사진 비교 개선

## 목적과 흐름

방문자가 첫 화면에서 진료 분야를 찾고, 분야별 상담 기준과 회복·주의사항을 확인한 뒤 상담을 준비할 수 있도록 정리했다.

흐름은 메인 배너 → 바로가기 메뉴 → 분야별 상세 → 사례·의료진·FAQ → 상담이다. 장식용 영문 라벨이나 반복 인트로는 추가하지 않았다.

## 적용 내용

1. 메인에서 24px 이상 스크롤하면 헤더 배경이 반투명해진다. 로고·메뉴·예약 버튼 위치는 유지하며, 메뉴를 열거나 키보드 포커스가 들어오면 배경을 불투명하게 표시한다.
2. PC는 배너와 바로가기 메뉴가 첫 화면 높이 안에 함께 들어오도록 조정했다. 모바일·태블릿은 배너 아래에 네 가지 진료 메뉴를 한 줄로 배치했다. 모바일 고정 상담 바의 높이도 확보했다.
3. 눈·코·윤곽·리프팅 상세 4개 페이지를 동일한 읽기 구조로 재구성했다. 진료 소개, 상담 계획과 진행 과정, 회복·사후관리, 마취·주의사항·한계, 비용 포함 항목, FAQ와 상담 폼으로 연결한다.
4. 상세페이지의 임의 금액 대신 비용에서 확인할 항목을 안내한다. 분야별 기존 설명과 임상 참고 데이터를 사용했으며 새로운 효과 수치나 회복 기간은 만들지 않았다.
5. 전후 사례 9개는 PC에서 **3열 × 3행**, 태블릿에서 2열, 모바일에서 1열로 배치한다. 부위 필터를 유지했다.
6. 원본 좌우 사진을 같은 크기로 겹쳐서 비교한다. 마우스 드래그, 터치, 키보드 방향키, 이전·이후 전체 보기 버튼을 지원한다. 이미지의 종횡비를 유지하고 새 크롭이나 재생성을 하지 않았다.
7. 메인 비교 이미지는 실제 전후 결과가 아니라 정면·측면 설명 이미지이므로 해당 라벨과 고지를 유지했다. 비교 페이지에도 AI 생성 이미지임을 표시했다.
8. 한국어 단어 단위 줄바꿈과 문단 너비, 제목 크기·행간을 정리했다. 불필요한 강제 줄바꿈을 제거하고 긴 문자열만 안전하게 줄바꿈한다.

## 스크롤·마우스 이벤트

추천한 효과 중 다음을 실제 적용했다.

- 상단의 얇은 읽기 진행 표시.
- 현재 읽는 상세 섹션을 강조하는 목차. PC에서는 좌측 고정, 작은 화면에서는 상단 고정으로 전환한다.
- 기존의 짧은 일회성 섹션 등장 효과 유지.
- 읽을거리, 시술 목록, 사례 카드에서 마우스 위치에 따라 최대 좌우 7px 이동. 사진 비교 중에는 움직임을 멈춘다.
- 사진 드래그 상태와 키보드 포커스를 명확하게 표시한다.

모션 감소 설정에서는 카드 이동과 관련 전환을 끈다. 터치 화면에서는 카드의 마우스 효과를 실행하지 않으며 사진 비교는 사용할 수 있다.

## 변경 파일과 구조

기존 React 19 + Vite + JSX + Vanilla CSS 구성을 유지했다. 패키지 추가는 없다.

```text
src/
  app/                              # 기존 URL 해석과 페이지 연결
  components/
    layout/SiteHeader.jsx           # 스크롤 헤더·읽기 진행 표시
    home/BeforeAfterGallery.jsx     # 메인의 촬영 각도 비교
    home/MediaJournal.jsx           # 마우스 반응 카드
    shared/
      BeforeAfterCompare.jsx        # 재사용 사진 비교
      comparison.mjs                # 좌표 계산·범위 제한
      PointerCard.jsx               # 카드 좌우 이동
      useActiveSection.js           # 현재 상세 목차
  pages/
    home/Home.jsx                   # 강제 줄바꿈 정리
    procedures/Procedures.jsx       # 목록 카드 반응
    procedures/ProcedureDetail.jsx  # 4개 상세 공통 템플릿
    collections/Collections.jsx     # 사례 앨범·비교
  data/                             # 기존 페이지별 콘텐츠·이미지·치수
  styles/interaction-upgrade.css    # 반응형·타이포·인터랙션
  main.jsx                          # 최종 스타일 연결
public/assets/                      # 기존 전용 이미지와 영상
tests/comparison.test.mjs            # 좌표·경계·유효하지 않은 측정값 검증
docs/                               # 변경 기록
```

그 밖의 페이지는 기존 콘텐츠를 유지하면서 공통 헤더와 줄바꿈 규칙을 적용한다.

## 실행과 빌드

최초 설치가 필요한 경우 프로젝트 폴더에서 `npm.cmd install`을 실행한다.

```powershell
npm.cmd run dev -- --host 127.0.0.1
npm.cmd test
npm.cmd run build
```

개발 서버는 `http://127.0.0.1:5173`, 빌드 결과는 `dist/`다.

## 검증과 해결한 문제

- 단위·데이터·경로 테스트 15개 통과.
- 17개 경로 × 3개 화면 너비, 51개 화면 검사: 이미지 깨짐·잘림·가로 넘침·중복 이미지·실행 예외 없음.
- 인터랙션 검사 26개: 첫 화면 메뉴, 반투명 헤더, 카드 이동과 복귀, 3×3 앨범, 사진 드래그·키보드·터치·전체 보기, 필터, 4개 상세 목차, 모션 감소 설정 확인.
- 상세 폼의 필드별 오류와 첫 오류 포커스, 입력 확인 상태를 추가 확인했다.
- 기존 `section[id]` 스타일과 상단 스크롤 여백이 중첩되어 목차 이동 위치가 과도하게 내려가는 문제를 수정했다. 실제 링크 이동과 목차 강조 기준을 같은 여백으로 계산한다.
- 태블릿의 한 줄 목차와 모바일의 두 줄 목차에 서로 다른 이동 여백을 적용한다. 고정 목차 배경은 화면 폭을 덮어 본문이 옆으로 비치지 않게 했다.

스크린샷과 상세 검사 결과는 로컬 `.taste-skill/interaction-audit/`, `.taste-skill/image-audit/`에 저장했다.

## 운영 전 확인 사항

현재 의료진·연락처·실제 환자 사례 데이터는 확인되지 않아 게시하지 않는다. 사진 비교 기능이 실제 임상 결과를 의미하지 않는다. 상담 양식은 입력 검증만 수행하며 서버 전송이나 예약 접수는 제공하지 않는다.
