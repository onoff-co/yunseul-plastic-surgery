# 전체 페이지 줄바꿈 정리

## 목적

메인에서 진료 분야를 찾고 상담 정보를 읽는 흐름을 유지하면서, 한국어 단어 중간 끊김·불필요한 강제 줄바꿈·과도하게 긴 문장 행을 정리했다. 기존 페이지와 콘텐츠를 유지하며 타이포그래피와 관련 열 너비만 조정했다.

## 변경 내용

- 병원 소개, 의료진, 상담 예약, 시술 목록에서 `<br>`를 제거했다. 문장의 의미와 안내 내용은 유지한다.
- 공통 텍스트에 한국어 단어 단위 줄바꿈을 적용한다. 컨테이너보다 긴 단어만 예외적으로 끊어 가로 넘침을 방지한다.
- 제목은 균형 있게, 긴 본문은 자연스럽게 줄바꿈한다. 짧은 소개·폼 안내·후기·푸터 설명은 줄 길이를 균형 있게 맞춘다.
- 긴 본문의 최대 너비는 42rem으로 제한한다. 상담 흐름 목록은 PC에서 제목/설명 두 열, 1023px 이하에서 한 열로 표시한다.
- 오시는 길의 방문 안내 문구는 좁은 빈 열에 갇히지 않도록 본문 너비를 확보했다.
- 작은 화면에서 상담 예약 제목의 크기와 의료진 약력의 열 배치를 조정했다. 후기 문장에도 단어 단위 줄바꿈을 적용했다.
- 메인 제목과 ‘부작용과 한계’는 의미 단위로 묶어 줄 끝에서 분리되지 않게 한다. 강제 개행 대신 사용 가능한 너비에 맞춰 묶음이 다음 줄로 이동한다.

## 변경 파일·구성

```text
src/
  styles/
    base.css                        # 전역 anywhere 줄바꿈 제거
    typography.css                  # 공통 읽기 너비·줄바꿈·반응형 규칙
  main.jsx                          # 최종 타이포 스타일 연결
  components/home/
    HeroSection.jsx                 # 두 배너 제목의 의미 단위 묶음
    BeforeAfterGallery.jsx          # 비교 안내 문구의 의미 단위 묶음
  pages/
    procedures/Procedures.jsx       # 시술 안내 강제 줄바꿈 제거
    about/About.jsx                 # 소개 제목 자연 개행
    doctors/Doctors.jsx             # 의료진 제목 자연 개행
    consultation/Consultation.jsx   # 상담 제목 자연 개행
    location/Location.jsx           # 방문 안내의 본문 너비
```

기존 React + Vite + JSX + Vanilla CSS 구성을 사용한다. 새 패키지는 필요하지 않다.

## 검증

- 17개 경로 × 320·390·768·1024·1440px, 총 85개 화면을 실제 Chromium에서 검사했다.
- 검사 범위에서 강제 `<br>` 0개, 제목 3줄 이상 0개, 본문 범위 밖 텍스트 0개, 페이지 가로 넘침·실행 예외 0개다.
- 마지막 줄에 1~3글자만 남고 바로 앞줄은 10글자 이상인 문단은 검사 범위에서 0개다. 모든 짧은 행을 오류로 보지는 않으며 최종 스크린샷을 함께 확인했다.
- FAQ 7개 경로 × 3개 너비에서 각 답변을 펼쳐 본문 범위를 추가 확인했다.
- 두 메인 배너 × 1440·390·320px에서 제목의 의미 단위가 나뉘지 않는 것과 첫 화면 진료 메뉴를 확인했다.
- 단위·경로·데이터 테스트 15개와 배포용 빌드 통과.

검사 결과와 PC·모바일 스크린샷: `.taste-skill/typography/before/`, `.taste-skill/typography/after/`.

## 실행

프로젝트 설치가 필요한 경우 `npm.cmd install`을 실행한다.

```powershell
npm.cmd run dev -- --host 127.0.0.1
npm.cmd test
npm.cmd run build
```

개발 서버: `http://127.0.0.1:5173`. 빌드 결과: `dist/`.

새 기능이나 추가 이미지가 필요하지 않은 수정이다. 실제 폰트와 브라우저에 따라 정확한 행 끝은 달라질 수 있으며, 줄바꿈 규칙과 반응형 너비는 함께 적용된다.
