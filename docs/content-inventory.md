# 콘텐츠 인벤토리

실제 병원명, 의료진 정보, 시술 설명, 가격, 사진, 운영시간과 법정 고지 내용을 확정한 뒤 작성합니다.

페이지별 본문 초안은 반영되었습니다. 출처와 적용 범위, 확인되지 않은 운영 정보는 [콘텐츠 작성 근거](content-reference.md)를 참고하세요.

- 홈: 상담 준비와 온라인 접수 상태를 반영한 FAQ 6개
- 병원 소개: 개인의 특징, 충분한 설명, 결정 이후의 관리
- 시술 안내: 상담 흐름과 분야별 탐색
- 시술 상세 4종: 고민 유형, 상담 항목, 회복 안내, 개별 FAQ
- 의료진: 상담 전 준비할 경험과 질문
- 오시는 길: 일정 확인, 교통 및 출입 안내, 준비 자료
- 상담 예약: 문의 준비, 일정 확인, 대면 상담의 순서
