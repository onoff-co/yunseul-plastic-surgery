# 윤슬 사이트 리디자인 기록

## 목적과 사용자 흐름

처음 방문한 사용자가 진료 분야를 고르고, 상담 기준과 사례를 확인한 후 상담을 준비하는 사이트다.

흐름: 메인 비주얼 → 진료 분야 → AI 생성 이미지 비교 → 읽을거리 → 공간 안내 → FAQ·상담 준비.

페이지 상단의 영문 장식, 번호 라벨, 반복 인트로는 사용하지 않는다. 하위 페이지에는 현재 위치를 짧게 표시하고, 화면에 보이지 않는 페이지 제목으로 접근성을 유지한다.

## 참고 사이트와 실제 반영

2026-10-27에 두 사이트의 브라우저 화면과 메뉴·콘텐츠를 확인했다. 레이아웃의 원리를 가져오고 사진·영상·카피·로고는 복제하지 않았다.

## 이미지와 영상

- AI 생성 인물·공간·장비·비교 이미지를 사용한다. 원본 PNG는 보존하고 웹용 JPEG를 별도로 생성했다.
- 메인 비주얼은 1,777,994바이트에서 109,048바이트로 줄었다. 전체 페이지의 체감 속도에 대한 실측 수치는 아니다.
- 공간 영상은 기존 AI 라운지 이미지의 시점을 천천히 이동시킨 9초 무음 WebM이다. 실제 병원 촬영 영상이 아니며 화면에도 이를 표시한다.
- 영상은 사용자가 재생하며, 자동 재생하지 않는다. 재생 실패 시 정지 이미지로 대체한다.
- 다른 병원 자료, 외부 스톡 영상이나 외부 아바타를 넣지 않았다.

## 인터랙션

- PC 메뉴: 포인터 진입, 키보드 포커스, 하위 메뉴 버튼. Escape로 닫는다.
- 모바일 메뉴: 열기/닫기, 배경 클릭, Escape, 화면 크기 변경 시 상태 초기화.
- 진료·사례·공간 선택은 버튼을 눌러 동작하며 선택 상태를 보조기술에 전달한다.
- 이미지 링크는 약 3.5% 확대, 링크는 밑줄 간격, 버튼은 배경색을 바꾼다.
- 콘텐츠는 숨겨 놓지 않는다. 짧은 등장 효과가 끝나기 전에도 읽을 수 있고, 동작 줄이기 설정에서는 효과를 없앤다.
- 상담 폼은 이름·전화번호·진료 분야·동의 여부를 확인하고 각 오류를 입력칸 가까이에 보여준다. 실제 서버 전송은 하지 않는다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1
```

기존 의존성이 설치되어 있으면 추가 설치 없이 개발 서버와 빌드를 실행할 수 있다. 배포 서버에는 기존과 같이 SPA fallback이 필요하다.

## 검증과 발견된 문제

- 기존 URL·데이터 테스트 9건 통과.
- 디자인 소스 검사: 0 FAIL, 0 WARN.
- 메인 1440·768·390px 실브라우저 검사: 0 FAIL, 3 WARN. 보고서와 스크린샷은 `.taste-skill/redesign-final/`에 저장했다.
- 색상은 사용자 지정 Warm Ivory를 유지했다. AI 이미지 고지는 장식 라벨이 아니므로 이 두 항목은 검사 예외로 기록했다(`palette-cream`, `eyebrow`).
- 남은 권고는 텍스트 크기 종류, 절제된 모션, 태블릿 FAQ 제목 옆 여백이다. 본문 16px과 보조 고지 13px, 타이틀별 크기 차이를 유지하며 과도한 모션을 추가하지 않았다.
- 320·768·1024·1440px에서 메인 가로 넘침이 없고, 1024px부터 PC 메뉴로 바뀌는 것을 확인했다.
- 병원 소개·의료진·시술 목록/상세·사례·후기·상담·위치·비용·공지·FAQ를 브라우저에서 확인했다.
- 진료 선택, 사례 필터, 9초 영상 재생/일시정지, 공간 전환, 모바일 메뉴, PC 하위 메뉴의 Enter·Escape를 확인했다.
- 상담 양식은 빈 입력 오류, 첫 오류 칸 포커스, 유효한 입력 확인을 검증했다. 확인 시점 브라우저 오류 로그는 없었다.
- 이미지의 HTML 높이 속성이 모바일 섹션을 과도하게 늘리던 문제는 CSS 높이 자동 계산으로 해결했다.
- 사례 원본 이미지와 시술 상세 하단 영역의 가로 넘침을 발견해 컨테이너 너비 기준으로 수정했다.
- 빌드/자동 브라우저 검사가 샌드박스 경로 접근 제한으로 실행되지 않던 경우, 승인된 실행 환경에서 다시 검증했다.
